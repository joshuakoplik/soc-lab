# Data Export Request Macro & SOP

**Owner:** Support Department  
**Last Updated:** October 14, 2023  
**Status:** Active

### Overview
This document provides the approved response macros for handling client requests for bulk data exports. To maintain system stability and security, all export requests must follow the verification protocol before a ticket is escalated to the Data Engineering team.

### Macro: Initial Request & Verification
*Use this macro when a client first requests a full historical dump or a custom CSV export of their analytics dashboard.*

**Macro Name:** `export_verification`  
**Text:** 
"Hello, I can certainly help you get that data exported. To ensure we are pulling the correct parameters and maintaining security protocols, please confirm the following:
1. The specific date range required (e.g., Jan 1, 2022, to present).
2. The desired format (CSV, JSON, or Parquet).
3. The specific Project IDs or Workspace tags that should be included in the pull.

Once you provide these details, I will initiate the request with our Data Engineering team. Please note that exports exceeding 5GB typically take 24–48 hours to process."

---

### Macro: Escalation to Engineering
*Use this macro once verification is complete and you are moving the ticket to the 'Engineering-Data' queue.*

**Macro Name:** `export_escalated`  
**Text:** 
"Thank you for those details. I have submitted a formal export ticket (Ref: DE-Export) to our Engineering team. They will generate the secure download link via our encrypted S3 bucket. You will receive an automated email notification once the file is ready for retrieval."

---

### Internal Processing Instructions
1. **Check Tier Status:** Before escalating, verify if the client is on the *Standard* or *Enterprise* plan. Standard users are limited to two bulk exports per calendar quarter. If they have exceeded this, refer them to the "Upgrade Options" macro.
2. **Size Estimation:** Check the `client_volume` metric in the Fenwick Admin Console. If the projected export exceeds 50GB, you must CC the Account Manager (AM) on the ticket to discuss potential compute costs.
3. **Security:** Never send raw data files directly via email attachments. All exports must be delivered through the secure S3 link generated by the Engineering team.
4. **SLA:** The turnaround time for standard exports is 2 business days. For "Critical" priority requests, ensure a valid reason is documented in the ticket notes before escalating.
